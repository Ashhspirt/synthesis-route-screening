虚线是冻结阈值 0.5844。分数描述的是规划器的历史结果，不是可合成性的结论。

从 SMILES 到筛选决定

整个流程在两个 CPU 线程上完成，不需要 GPU。单次预测只需加载三个冻结模型。

解析结构

读入 SMILES，无效输入会明确报错，不会静默跳过。

编码特征

Morgan 计数指纹（半径 2，1,024 位）经 log1p，加上只用训练集缩放的 5 个描述符，共 1,029 维。

三个网络打分

隐层 256 → 128 → 64，ReLU，dropout 0.2。种子 42、43、44 各训练一个，按验证损失恢复最佳检查点。

平均并决策

三个 sigmoid 输出取平均，达到 0.5844 就标记为优先。阈值在验证集上选出，偏向少漏候选。

使用前请了解它的盲区

结构越复杂，模型越容易把有路线的分子推迟。下面是召回导向阈值下各结构子组的漏检率，即历史上找到路线却被推迟的比例。

漏检率：复杂结构与其余分子

橙色为复杂结构组，灰色为其余分子。

这个分数描述的是 AiZynthFinder 历史上是否找到了路线。它不提供反应路线、条件或产率，评估一条合成路线仍需要化学家判断。

环数超过 4 的分子，漏检率达到 26.51%，约是其余分子的四倍。对环系复杂的候选，不建议只凭这个分数推迟。

在本地运行

只看交互式讲解

只需要 Python 标准库，不用安装机器学习依赖。

python scripts/serve_demo.py

为新分子打分

需要 Python 3.12 和锁定的依赖环境，详见仓库 README。

python scripts/predict.py \
  --smiles "CCO" \
  --smiles "CC(=O)Oc1ccccc1C(=O)O"
